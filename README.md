# Muralikrishnan Menon — Portfolio

Personal portfolio website for Muralikrishnan Menon, a Computer Science student and developer interested in web applications, systems, networking, automation, and creative problem-solving.

## Highlights

- Responsive single-page portfolio built with HTML, CSS, and vanilla JavaScript
- Light and dark themes with a charcoal, earth-brown, and burnt-amber dark palette
- Mobile-friendly fixed navigation and responsive layouts
- Project showcase with GitHub links
- Interactive custom cursor and subtle motion effects
- Contact links, résumé download, and a small keyboard Easter egg
- No framework or build step required

## Files

- `index.html` — website structure, styles, and JavaScript
- `resume.pdf` — résumé linked from the contact section
- `mohanlal.png` — Easter egg image

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to Vercel

This is a static website and does not require a build command or framework. Import the repository into Vercel and use the project root as the root directory. Leave the build command empty.
